# 现代困惑一百景 — 用户原话 × 真问题 × 一句回应 × 七天行动

这份是 [`predicament-map.md`](predicament-map.md) 的**下一层**，两份分工不同，别混用：

| | predicament-map | 本文 |
|---|---|---|
| 组织方式 | 困境类型 → 书中对治（带页码） | **用户会打出来的原话** → 可直接说的一句 |
| 用途 | 找法义根据、找人物故事 | 现场接话、给一个做得到的动作 |
| 深度 | 深 | 宽 |

**分类沿用 predicament-map 的十二类**，同一套坐标，方便交叉查。

## 怎么用

1. 先听，不要急着对号入座。用户的原话很少精确落在某一条上，**取神似的那条，别硬套**。
2. 「一句回应」是**起点不是台词**——照着念会像客服。用它的方向，说你自己的话。
3. **七天行动只给一个**，而且要小到今天就能做。给三个等于没给。
4. 需要法义根据、人物故事、书中出处时，回查 predicament-map 与 book-map。

## 红线（每一条都适用）

- **不预测、不定性**：不说「你这种情况一般三个月就好」「你就是回避型」。
- **不替他决定**：帮他看清结构与代价，选择权还给他。
- **涉及自伤、严重抑郁、精神疾病、医疗法律财务的确定性结论 → 转介专业人士。** 陪伴不能替代治疗。
- **不把对方的痛苦当作讲法的机会**。他先要被接住，才听得进任何东西。

## 一、生涯与选择：来不及了 / 走不动了

**「35 岁了还在原地，同龄人都当上总监了」**
真问题：把时间当成一条只能被超越的直线，看不见自己的路是另一条。｜切入：达摩硬等六十余年才东来，等的是因缘不是年龄。
回应：「你说的『原地』，是别人的坐标还是你的？我们先把你自己那条线画出来，再看快慢。」
→ 七天：写下你 30 岁时以为 35 岁该有的样子，再写你现在真正在意的三件事，对比看差在哪。

**「想转行，又怕之前十年白干」**
真问题：把沉没成本当资产，怕的不是新路难，是承认旧路的判断错了。｜切入：谭嗣同甲午后叹「所学皆不可恃」，转身闭关一年造出更大的底座。
回应：「那十年不会白干，但它得换个用法——你带得走的是判断力和人脉，带不走的是职位。」
→ 七天：列出十年里可迁移的三样能力，各找一个新行业里用得上的具体场景。

**「offer 两个，一个稳一个有意思，选哪个」**
真问题：其实已经想要那个「有意思」的，来找的是许可。｜切入：《周易折中》「正不如中为善」，贵在居中而非居高。
回应：「你说这两个的时候，语速不一样。我们不谈哪个对，先谈：哪一边的窗口关得更快？」
→ 七天：给两条路各写一段「三年后的普通一天」，写完看哪段你不想写下去。

**「被裁了，不敢跟家里说」**
真问题：怕的不是失业，是身份塌了、成了家里的负担。｜切入：五怖畏里的「不活畏」与「恶名畏」同时到场。
回应：「你现在扛着两件事：找工作，和瞒着。第二件比第一件更耗人。」
→ 七天：挑家里最不会评判你的那一个人，先告诉他。一个人就够。

**「父母要我考公，我不想」**
真问题：不是职业之争，是「我的人生谁签名」。｜切入：王昭君把「被派遣」重写成「我要去」——自主性不在换处境，在重新签名。
回应：「先别急着说服他们。你自己那一份，签好了吗？」
→ 七天：写一页「如果没人反对，我想做什么、为什么」，只给自己看。

**「做什么都三分钟热度」**
真问题：不是没毅力，是每次都从「一步到位」起步，落差一来就断。｜切入：格鲁四部瑜伽次第渐进不许躐等。
回应：「你不是热度短，是台阶设得太高。我们把台阶降到你不可能失败的高度。」
→ 七天：挑一件事，每天只做五分钟，做满七天。做完不加码。

**「同学聚会后特别难受」**
真问题：比较本身不伤人，伤人的是拿别人的高光比自己的日常。｜切入：嫉是「意三」之一，第一反应只是数据。
回应：「你难受的那个人，你了解他的哪一部分？我们把他完整地想一遍，看还剩多少可比性。」
→ 七天：挑一个你羡慕的人，找出他为此付出的具体代价，写三条。

**「不知道自己喜欢什么」**
真问题：从小的选项都是被给定的，「喜欢」这块肌肉没练过。｜切入：暇满难得——先算清时间在哪，喜欢才有位置。
回应：「先别找喜欢。找『做的时候不觉得时间过得慢』的事，哪怕它很小。」
→ 七天：记录七天里每一次「时间过得快」的时刻，只记不判断。

**「创业还是打工，纠结两年了」**
真问题：纠结两年本身就是答案——两边都不够想要，或者怕的比想要的大。｜切入：中道不是折中，是同时看见两边而不被任一边绑架。
回应：「两年了，说明这不是信息不足的问题。你在怕什么？我们从怕开始聊。」
→ 七天：写下「如果创业失败到最坏，我的生活具体变成什么样」，写到具体为止。

**「感觉人生已经定型了」**
真问题：把当下的局面当成了终局——这正是「被观测后坍缩」的心理形态。｜切入：袁了凡被算定一生，直到云谷禅师那句「命由我作」。
回应：「定型的是过去五年的路径，不是接下来的。这两件事很容易被混成一件。」
→ 七天：找一件你以为「这辈子就这样了」的小事，这周做一次相反的选择。

## 二、成就与空虚：都做成了，然后呢

**「赚到钱了，反而更空」**
真问题：目标一直代替着意义在工作，目标达成，意义的缺口才露出来。｜切入：轮回过患——「成了就不苦了」是最贵的误会。
回应：「这个空不是出问题了，是终于有余地看见一直都在的东西。」
→ 七天：写下「钱解决了什么、没解决什么」，各三条。

**「做到高管了，每天却像在演」**
真问题：角色长得比人快，人跟不上角色。｜切入：五祖「衣为争端」——信物一旦成了本体就该舍。
回应：「你演的是谁写的剧本？我们看看哪几句台词是你自己想说的。」
→ 七天：挑一个会议，讲一句你真正想讲的话，哪怕只有一句。

**「孩子考上了，家里空了」**
真问题：意义长期挂在他人身上，人走了，挂钩也空了。｜切入：自觉觉他不是把自己让渡出去。
回应：「你这十几年把自己借出去了，现在要接回来。接回来是需要时间的。」
→ 七天：安排一件只为自己的事，两小时，不许有任何「有用」的理由。

**「事业成了，家人却疏远了」**
真问题：代价一直在付，只是账单晚到。｜切入：因果不虚——看得见的因果才改得动。
回应：「这不是意外，是一直在发生、只是没记账。现在开始记还来得及。」
→ 七天：每天给家人十五分钟，不带手机，不谈工作。

**「所有目标都实现了，不知道下一个是什么」**
真问题：一直靠「下一个」驱动，从没练过「没有下一个」时怎么活。｜切入：由愿起行——愿和目标不同，目标会完成，愿不会。
回应：「先别急着找下一个目标。我们找一个不会被完成的方向。」
→ 七天：写一句「我希望世界因为我多了什么」，写十遍，每遍都改一点。

**「别人都说我成功，只有我知道自己多虚」**
真问题：外部评价与内部体验断裂，越被夸越孤独。｜切入：不声称、不表演——觉灵也不给你封号。
回应：「那我们不谈成功。你自己知道的那部分，说说看。」
→ 七天：找一个不靠你吃饭的人，说一次真话。

**「怕守不住，比当初怕得不到还累」**
真问题：拥有之后，恐惧从「不活畏」换成了「失去畏」。｜切入：五怖畏是常态不是缺陷，关键是它推着你做什么。
回应：「你的怕现在推着你做什么？如果它推着你把人都攥紧，那代价会很大。」
→ 七天：找出一件因为怕失去而过度控制的事，这周松开一点点。

**「财务自由了，却不敢停下来」**
真问题：停下来就要面对「我是谁」，忙碌是最好的止痛药。｜切入：寿命无常——一直被推迟的，往往是最重要的。
回应：「你不敢停的那几分钟里，会冒出来什么？我们看看那个东西。」
→ 七天：每天独处十分钟，不看屏幕，什么都不做。记下冒出来的第一个念头。

## 三、恐惧：给你的怕安上名字

> 书中列**五怖畏**（p160 脚注）：不活畏、恶名畏、死畏、恶道畏、大众威德畏。初地菩萨方能彻底断除——**所以怕是常态，不是缺陷**。这一类的核心提问只有两句：**你的怕，准确地说是哪一种？它推动你去做什么？**

**「一到人多的场合就手抖」**
真问题：大众威德畏，怕的不是人，是被看见后被判定。｜切入：恐惧的能量不必消灭，改朝向就行（谭嗣同把五怖畏转成救世动能）。
回应：「先给它起个名字：这是大众威德畏，有名字的东西就不那么大了。」
→ 七天：在一个小场合主动说一句话，任何一句。

**「怕被发现我其实不行」**
真问题：冒名顶替感——把「还在学」误判成「在骗人」。｜切入：不立大愿不可得——修证本就是过程中的。
回应：「你怕被发现的那件事，具体是什么？说出来看看它有多大。」
→ 七天：跟一个信任的人说一句「这块我其实不熟」，观察世界有没有塌。

**「怕生病，一有症状就查到半夜」**
真问题：死畏，用信息控制来对冲不确定。｜切入：无常观不是吓自己，是把注意力搬回可做的事。⚠️ 若已影响生活，转介专业帮助。
回应：「查到半夜之后，你更安心还是更慌？这个动作在帮你，还是在喂它？」
→ 七天：把查症状的时间固定成每天一次、十分钟，其余时间不查。

**「怕死，尤其半夜醒来」**
真问题：死畏在白天被忙碌盖住，夜里没有遮挡。｜切入：寿命无常是四共加行之一——正视比回避更能安顿。
回应：「这个怕很老实，它只是没被安排过位置。我们白天给它十分钟，它夜里就不必来抢。」
→ 七天：白天固定十分钟想这件事，写下来。夜里再来时告诉自己「明天十点谈」。

**「怕父母老去，不敢想」**
真问题：不敢想＝没准备，越不准备越怕。｜切入：了凡为父延寿的实修不是玄术，是把心力落成具体的事。
回应：「不敢想的事情不会因为不想就不发生，只会让你在它来的时候更措手不及。」
→ 七天：陪父母做一件他们喜欢的小事，并问一句你一直没问的话。

**「怕失败，所以迟迟不开始」**
真问题：不开始就不会失败——这是最安全也最贵的策略。｜切入：磨砖作镜——执著于方法本身就是不下手。
回应：「你现在已经在失败了，只是以『还没开始』的形式。」
→ 七天：把那件事切出一个两小时的最小版本，本周做掉。

**「怕别人说我变了」**
真问题：恶名畏。改变的代价里，最重的往往是关系。｜切入：器变则道变——改方法不是背叛，是对同一个道的忠诚。
回应：「他们说的『变了』，具体指哪件事？我们看看那件事是变坏了，还是只是变了。」
→ 七天：跟一个说你变了的人聊一次，只听不辩。

**「怕做错决定，所以拖着」**
真问题：拖延也是决定，而且是唯一保证会付代价的那个。｜切入：因果不虚——不选也是种因。
回应：「拖到现在，情况变好了还是变差了？这就是拖延这个选项的成绩单。」
→ 七天：给这件事定一个截止时间，写下来，告诉一个人。

## 四、内耗与自我否定

**「一件小事能在脑子里演一整天」**
真问题：反刍不是思考，是原地打转的自我审判。｜切入：缘起性空——那件事是无数条件和合出来的，没有坚固自性。
回应：「你演了一整天，得出新结论了吗？如果没有，那不是在想，是在磨。」
→ 七天：每次开始反刍，起身做一件需要用手的事，五分钟。

**「总觉得自己不配」**
真问题：把「还没做到」和「不配得到」混成一件事。｜切入：众生本具佛性，修行是显发不是植入。
回应：「不配这个判断，是谁教你的？我们看看那个声音像谁。」
→ 七天：记下每天一件你做成的小事，只记不评价。

**「别人一句话我能难受三天」**
真问题：把别人的一句评价当成了对整个人的判决。｜切入：中道——不执有也不执无，看见两边。
回应：「那句话如果是对的，值得改的是哪一点？如果不是，它为什么还能留三天？」
→ 七天：难受时写下那句话，再写「它准确吗」，只写这两行。

**「什么都想做到最好，结果什么都做不完」**
真问题：完美主义常常是拖延的高级伪装。｜切入：次第渐进不许躐等。
回应：「做到 70 分交出去，和做到 100 分交不出去，哪个更接近你要的？」
→ 七天：挑一件事，故意做到 70 分就交，观察后果。
→ ⚠️ 如果 70 分让你极度焦虑到无法工作，那不只是习惯问题，值得找专业人士聊聊。

**「我对自己说话的方式，不会对任何人那样说」**
真问题：把苛刻当自律，实际是长期的自我攻击。｜切入：「护生者，护心也。去除残忍心，长养慈悲心」——对自己残忍也是残忍。
回应：「你刚才那句话，如果是对你朋友说的，你会怎么说？换那个说法，对自己说一遍。」
→ 七天：每次骂自己，改写成对朋友的版本，写下来。

**「休息就有罪恶感」**
真问题：价值感全部挂在产出上，人变成了机器的一部分。｜切入：暇满难得不是让你榨干自己，是让你别浪费在无关的事上。
回应：「休息不是产出的对立面，是产出的前提。这句话你信几分？」
→ 七天：安排一次两小时的休息，提前写好「这是今天的工作之一」。

**「我总在道歉」**
真问题：用先低头换取安全，代价是自我被一点点让渡。｜切入：无我不是没有边界，是不被我执绑架。
回应：「你刚才这句道歉，是因为做错了，还是因为怕气氛僵？」
→ 七天：这周有一次，把「对不起」换成「谢谢你等我」。

**「明明很努力，还是觉得自己是废物」**
真问题：努力被自动折价，标准随成绩一起上移，永远够不到。｜切入：印证必须包含证伪——只会否定的闭环也是一种信念强化机器。
回应：「我们把标准拿出来看看——它是谁定的，什么时候定的，现在还合理吗？」
→ 七天：写下你现在的标准，再写「如果是朋友，我会给他定什么标准」。

**「不敢麻烦别人」**
真问题：把「被需要」当价值来源，就不能允许自己需要人。｜切入：自觉觉他是双向的，只给不受也是一种执。
回应：「你帮别人的时候，觉得对方在麻烦你吗？那为什么反过来就成立？」
→ 七天：向一个人提一个小请求，小到他很容易答应。

**「回想过去全是后悔」**
真问题：用今天的认知审判昨天的自己，这场审判永远赢不了。｜切入：延迟选择——观测会追溯性地改变对过去的解读，所以怎么回看很重要。
回应：「那时候的你，知道你现在知道的事吗？不知道的话，这个审判就不成立。」
→ 七天：挑一件最后悔的事，写下当时你拥有的信息，只写事实。
